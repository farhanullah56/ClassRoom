# Snap Class

A smart classroom management app. Teachers and students log in separately,
and attendance can be taken by picture or by voice.

## Features
- **FaceID login:** log in with your face, or with a password
- **Picture attendance:** mark attendance from a photo of the class
- **Voice attendance:** mark attendance by voice
- **Course records:** add and manage courses
- **Attendance records:** view attendance history and reports
- **Separate portals:** one for students and one for teachers

## Built With
- Python
- Streamlit (front end)
- Supabase (database)

## How to Run
1. Clone the repository
2. Install the requirements: `pip install -r requirements.txt`
3. Add your Supabase keys
4. Run: `streamlit run app.py`
